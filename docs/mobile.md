# 手机浏览器与 fnOS App

FnTuiOS 使用同一条已认证的 NAS 网关和同一套用户会话提供桌面与触控界面。
手机无需另开服务端口，也不使用上游尚未公开的原生手机 App。

窄屏触控客户端以当前终端为主。键栏中的“会话”打开会话选择，“侧栏”进入当前客户端的全宽导航；使用 Esc 返回终端。
导航临时覆盖终端，不改变共享会话的侧栏开关、保存的桌面配置或其他客户端的侧栏空间。
宽屏触控客户端保留上游侧栏布局。操作键从实际按键绑定解析；无法编码的绑定不会显示为可执行按钮。

手机键栏继续由 sip/webterm 提供：特殊键、前缀、修饰键状态、触控手势与软键盘占用处理复用上游实现；软键盘是否允许唤起由 FnTuiOS 面板控制。
手机输入适配补齐只有提交事件携带文字的中文输入、没有有效按键事件的软键盘退格与向前删除。预编辑和选词过程不向终端发送拼音或回车；提交后的重复通知只归入同一次编辑，连续提交相同文字仍会分别保留。删除按当前协商的终端键盘协议编码，实体退格保留原生路径。
输入法剪贴板通过粘贴事件或编辑事件提交的文字沿用 WebTerm 粘贴接口，保留中文、换行及括号粘贴模式。手机继续使用原生终端输入框；其本地编辑锚点让输入法在文字已发送后仍能连续退格，锚点不会发送到终端。输入法短暂失焦或候选栏切换不撤销键盘授权，明确关闭、稳定收起、只读、断连或页面退出时才清理。
触控客户端首次连接使用上游的 `StartInTerminalMode` 选项进入输入模式，避免把输入当成窗口管理快捷键；桌面启动模式和保存配置保持原样。
主动退出输入模式后，默认双击终端内容重新进入；修改过 `appearance.click_to_type` 时遵循该配置。进入输入模式不会自动唤起系统键盘。
后端控制使用独立悬浮按钮，手机和桌面均支持拖动并保存当前位置。面板打开后 5 秒无操作会收起面板，并让按钮吸附最近边缘、半隐藏；面板内点击、按键或滚动会重新计时。点击关闭会立即半隐藏；面板关闭时拖动按钮，结束 3 秒后半隐藏。两种客户端复用同一套行为。手机键栏不再重复放置“控制”入口；底边半隐藏部分会裁剪，避免覆盖键栏。
控制面板使用实际可见视口并避让键栏。它不发送终端按键，停止和重启仍要求确认，所有控制继续由后端校验当前 NAS 用户。
业务后端停止后，独立停机页面保留启动入口。

布局依据可用宽高和触控能力，不能用它判断 fnOS 宿主身份或权限。
fnOS App 与独立浏览器的 SDK 能力分别遵循飞牛平台接口；仅终端和布局适配不额外申请文件授权等平台能力。

源码适配由 `scripts/mobile.py` 在本地化投影后应用，模板位于 `adapters/mobile/`；上游锚点变化时明确失败。
Go 检查覆盖移动侧栏的客户端边界和重绑定操作。运行面板浏览器验证同时覆盖桌面、触控入口、横竖屏和模拟键盘几何变化。
桌面 Chrome 的触控模拟不能代替真实 Android fnOS App、物理软键盘、中文 IME、系统返回与后台恢复验证。

## 悬浮面板输入与分屏

桌面面板提供上/下、左/右两行分屏，作用于当前窗格的 BSP 平铺布局；窗格过小、未启用 BSP 平铺、只读或连接异常时拒绝操作并提示原因。该入口使用已认证的有序控制通道，不依赖用户的快捷键绑定，也不向 shell 输入命令。

触控设备在面板中选择 Ctrl、Shift、Alt（可多选），再点击方向键；发送后修饰键自动复位，方向键操作保留面板。编码遵循当前终端协商的键盘协议。只读与断连时这些入口禁用。

“添加照片”打开系统图片选择器，取消不发起上传；支持 PNG、JPEG、GIF 和 WebP，文件大小及格式由现有上传链路校验。选定后捕获当前终端窗格，上传完成只插入 NAS 上的图片路径，不自动按回车。随后切换焦点不会把路径插入其他窗格；关闭目标或更换会话会使原操作失效。

手机面板末行由“添加照片”和“键盘”各占一半，桌面不显示这两个手机入口。“键盘”名称固定，用选中状态表示已开启；点击切换系统软键盘，并关闭面板返回终端。键盘默认关闭，原生键栏的 abc/hide 开关不显示；点击终端、普通键栏操作、连接完成、复制和照片上传完成均不能自行唤起它。系统收起键盘后也需再次使用该入口开启。打开或关闭管理面板时，已开启的键盘焦点保持；只读或断连时键盘入口禁用。

## 复制窗格文本

面板中的“终端显示”和“复制文本”并排显示。“复制文本”打开当前窗格的纯文本快照，不包含 TUIOS 边框、工具栏或其他分屏。手机打开该窗口时收起终端软键盘，阅读和选择文字不会唤起键盘。

选择“当前屏幕”或“历史输出”，用系统原生长按手柄或鼠标拖选文字，再点击“复制所选”；“复制全部”复制当前显示的文本。终端继续运行，快照通过“重新读取”更新。历史输出包含屏幕和该窗格保留的滚动记录，最多保留最近 20000 行历史及 2 MiB 文本，超出时提示截断。应用自身未输出到终端、或已从滚动记录淘汰的内容无法读取。

读取沿用当前登录连接和当前窗格绑定，浏览器不能指定其他窗格。只读连接可以复制；断连会清空快照。剪贴板复用上游 sip 的复制接口及非安全上下文回退；若宿主浏览器拒绝剪贴板权限，可使用选中文字后的系统复制菜单。

## 切换终端

底部第一排操作键可以左右滑动：“下一个”和“上一个”切换窗格，“会话”打开会话选择，“放大”切换当前窗格铺满显示。外接键盘默认使用 Alt+N、Alt+P 切换窗格；Ctrl+B 后按方向键切换相邻分屏。按钮按实际快捷键配置解析，自定义绑定时遵循对应配置。
